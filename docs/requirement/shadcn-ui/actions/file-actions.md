## Example behavior

- Use a fixed document list with open, rename, and duplicate actions.
- Reflect each action in the local file list or selected-document summary.
- Expose the same context actions through a normal button and right-click.

## Acceptance checks

- [ ] Keyboard users can reach every action without right-click.
- [ ] Rename and duplicate visibly update only this scenario; reset restores fixtures.

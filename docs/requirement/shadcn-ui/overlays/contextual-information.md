## Example behavior

- Use a Popover for local filtering, a member Hover Card for a profile summary, and Tooltips for labeled icon actions.
- Ensure contextual information is reachable through keyboard-accessible triggers.

## Acceptance checks

- [ ] Filters affect a local result summary.
- [ ] Helpful information is not available only on hover; overlays close and return focus correctly.
